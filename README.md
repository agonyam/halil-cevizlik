# Akçakoyun 3D Terrain Survey

Static GitHub Pages viewer for the WebODM reconstruction captured on 23 August 2026.

The viewer requires no backend. It loads the self-contained GLB model from `assets/` and uses Three.js from jsDelivr.

Visitors can optionally tap **Show my location** to place their phone GPS position on the georeferenced model. Location data stays in the browser and is not uploaded or stored.
